Add the input method.

Install and register Hufu. Open System Settings → Keyboard → Input Sources and add Hufu. If it is missing, log out and back in, then check again.

After an update, let macOS launch the input process when you next type. Do not launch it manually as a normal app.

The first time Hufu Settings opens, a guide confirms the input method is enabled, lets you pick the page size and script mode (importing Squirrel when found), sets a few habits and gives you a practice field. Sample phrases: zhmn → 虎码, jxbh → 你好, tuja → 我们, dgrn → 中国. Run it again from Advanced › First-run guide.

Installation instructions

Configure RIME visually.

Open Hufu Settings from the input menu to adjust candidates, script mode, shortcuts and appearance; changes apply a few seconds later.

Visual settings cover candidates, page keys, Chinese/English switching, the four script modes and Traditional standard, word input, convenience inputs, shortcuts and appearance. Switch between mixed, Traditional output, Traditional only and Simplified only; ⌃O or ⌃⇧4 flips it for the session. Each app can start in English, Chinese or the shared state.

Visual preferences and hand-written configuration are kept in separate layers. Advanced RIME configuration remains available.

Quick menu & snippets.

Hold ⌥ on its own for about 0.35 s to open the quick menu (switchable to ⌃, ⌘ or off). Space opens AI actions; digits 1–4 open snippets, symbols, frequent words and settings, and work while ⌥ is still held.

The symbol board is laid out like your keyboard, 10 × 3; press the matching letter to insert. Snippets live in your own categories (IDs, phone numbers, addresses…) under Settings › Snippets, stored owner-only on this Mac, never synced and never given to AI.

Typing statistics are optional and off by default. They keep, on this Mac, character counts by time of day and by app, plus 2–8 character Chinese words with their counts. No full sentences are saved. The data stays offline and can be cleared at any time.

Local data details

Migrate from Squirrel.

Sync user data in Squirrel first, then import from Hufu Settings. The importer reads the original Rime directory without writing to it.

Schemas, vocabulary, Lua, themes and user frequency snapshots are imported. Keep a backup of important configuration.

Word input and tables.

The official Tiger-Code vocabulary ships with the installer: the main table holds single characters and your own phrases, and three word tables are prebuilt. Settings › Typing › word input is off by default; when enabled it mounts the table that matches the script mode — mixed uses the simplified table plus the traditional-code table, Traditional output a pre-converted table, Traditional only the traditional-code table and Simplified only the simplified one.

The input method never downloads word lists. Custom phrases live in the huma_custom table with hand-written Tiger-Code codes and merge into the main dictionary on the next automatic deploy.

Vocabulary notes

Use AI explicitly.

Enable AI features, then press ⌃⌥P, or hold ⌥ and press Space, to choose translate, polish or a custom action. Simplified/Traditional conversion runs locally and works without AI. AI works on, in order: the draft in the input layer, your selection, or what you just typed in this field; while choosing a candidate, it commits that candidate first and handles only that word. The website shows fixed examples.

The default is Apple’s on-device model, whose availability depends on your device, system settings and region (currently unavailable for mainland China devices and accounts). Otherwise, configure your own OpenAI-compatible endpoint (may be billed); it requires separate permission to send target text. There is no automatic cloud fallback.

Read privacy details

Disable and uninstall.

Switch to another input method and remove Hufu in System Settings first. The development app is installed in your user Library Input Methods directory.

Your configuration and word frequency data live separately. Uninstalling the app and removing personal data are separate actions; back up before removing data.
