Hufu 的代码和依赖

Hufu 是基于 librime 的独立 macOS 前端，不是鼠须管的分支。原创代码采用 MIT；librime、OpenCC 等第三方组件与虎码方案各自保留原许可。

GitHub · syhily/hufu 词库目录 · dicts/huma 
git clone https://github.com/syhily/hufu.git

Hufu 不捆绑任何原生插件：librime 及其依赖以静态库形式内嵌，安装包不含 GPL 组件；虎码词表按官方发布条款随包提供，对应源码与词表随 GitHub Release 提供。
