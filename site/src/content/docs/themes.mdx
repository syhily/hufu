8 套配色，都是 App 实际渲染。点「安装到 Hufu」由设置确认导入，也可以复制 YAML 手动加入配置。

<ThemeGallery />

需要 Hufu 0.1.0 或更新版本；点击后由虎符输入法设置确认导入。也可复制 YAML 手动导入 `hufu/imported/hufu.custom.yaml`。

安装链接可直接使用；复制链接与 YAML 需要启用 JavaScript。

想要自己的配色：在「设置 › 外观」里调整背景、文字、高亮与圆角字号，另存为「我的配色」，或把上面的 YAML 改好后粘贴进去。
