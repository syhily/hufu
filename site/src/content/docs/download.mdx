## 按步骤安装。

1. 下载安装包和同一 Release 里的 SHA256SUMS.txt，运行以下命令校验。

```
shasum -a 256 -c SHA256SUMS.txt --ignore-missing
```

2. 右键 › 打开安装包，按提示安装。首次打开被系统拦下时，到「系统设置 › 隐私与安全性」点「仍要打开」。

```
xattr -d com.apple.quarantine Hufu-0.1.0.pkg
```

3. 打开系统设置 → 键盘 → 输入法 → 编辑…，点 +，在「简体中文」中添加虎符输入法。首次安装后若没有出现，注销后重新登录。

## 也可以从源码构建。

需要 Xcode 26+、cmake 与 XcodeGen。脚本下载并校验固定版本的 librime 依赖，再构建和注册输入法；本地构建结果是 ad-hoc 签名。

```
git clone https://github.com/syhily/hufu.git && cd hufu
bash scripts/install-dev.sh
```

安装新版后，下次输入时由系统启动输入法进程。不要手动启动。
