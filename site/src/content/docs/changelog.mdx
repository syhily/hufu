## 0.1.0：首个公开版本。

**预览版 · 未签名**

只做虎码的 macOS 输入法：librime 静态内嵌，虎码官方秃版词库随包提供；单字默认，词汇输入按简繁模式挂载三张词表；简繁四模式与繁体标准；/time、/date、=计算器、/数字大写等便利输入；主题 hufu_light / hufu_dark / 自定义与 hufu-ime:// 一键导入；输入统计默认关闭、纯本地。当前为 ad-hoc 预览版，签名与公证待开发者账号。
