8 套配色，都是 App 實際渲染。點「安裝到 Hufu」由設定確認匯入，也可以複製 YAML 手動加入配置。

<ThemeGallery />

需要 Hufu 0.1.0 或更新版本；點擊後由虎符輸入法設定確認匯入。也可複製 YAML 手動匯入 `hufu/imported/hufu.custom.yaml`。

安裝連結可直接使用；複製連結與 YAML 需要啟用 JavaScript。

想要自己的配色：在「設定 › 外觀」裡調整背景、文字、高亮與圓角字號，另存為「我的配色」，或把上面的 YAML 改好後貼進去。
