## Hufu 的程式碼和依賴。

Hufu 是基於 librime 的獨立 macOS 前端，不是鼠須管的分支。原創程式碼採用 MIT；librime、OpenCC 等第三方元件與虎碼方案各自保留原許可。

[GitHub · syhily/hufu](https://github.com/syhily/hufu)　[詞庫目錄 · dicts/huma](https://github.com/syhily/hufu/tree/main/dicts/huma)

```
git clone https://github.com/syhily/hufu.git
```

Hufu 不捆綁任何原生外掛：librime 與其依賴以靜態庫形式內嵌，安裝包不含 GPL 元件；虎碼詞表按官方發布條款隨包提供，對應原始碼與詞表隨 GitHub Release 提供。

[第三方宣告](https://github.com/syhily/hufu/blob/main/docs/license-packaging-verification.md)　[Releases 與對應原始碼](https://github.com/syhily/hufu/releases)　[MIT 許可全文](https://github.com/syhily/hufu/blob/main/LICENSE)
