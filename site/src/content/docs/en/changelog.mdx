Changes to the input method and this website: releases, installers and documentation.

**2026.10.21**

## 0.1.0: first public release.

**Preview · unsigned**

A macOS input method for Tiger-Code only: librime linked statically, the official vocabulary bundled; single characters by default, word input mounting the three tables that match the script mode; four script modes and Traditional standards; convenience inputs (/time, /date, =calculator, /number); hufu_light / hufu_dark / custom themes with one-click hufu-ime:// import; typing statistics off by default and purely local. This is an ad-hoc preview: signing and notarization wait for a developer account.

[View release](https://github.com/syhily/hufu/releases)
