## Hufu code and dependencies.

Hufu is an independent macOS frontend based on librime, not a Squirrel fork. Original code uses MIT; librime, OpenCC and the Tiger-Code schema keep their own licenses.

[GitHub · syhily/hufu](https://github.com/syhily/hufu)　[Tables · dicts/huma](https://github.com/syhily/hufu/tree/main/dicts/huma)

```
git clone https://github.com/syhily/hufu.git
```

Hufu bundles no native plugins: librime and its dependencies are linked statically, and the installer contains no GPL component. The Tiger-Code word lists ship under their official release terms, and sources travel with each GitHub Release.
