import { Card, CardGrid } from '@astrojs/starlight/components';

<CardGrid>
  <Card title="Tiger-Code only" icon="star">
    The schema list holds one entry, `tigress`. The official 秃版 2026.08.15 data comes from `dicts/huma`, trimmed to single characters and phrases of up to four characters.
  </Card>
  <Card title="Word input" icon="open-book">
    Off by default: single characters and your own phrases only. Turned on, it mounts the table that matches the script mode — simplified, the pre-converted Traditional table, or traditional codes. Tables are prebuilt at build time.
  </Card>
  <Card title="Four script modes" icon="translate">
    Mixed ranks candidates by 《通用规范汉字表》 tier; Traditional output, Traditional only and Simplified only come with it. The Traditional standard can be Tiger-Code `st_tu`, Taiwan, Hong Kong or generic.
  </Card>
  <Card title="Convenience inputs" icon="rocket">
    `/time`, `/date`, `/week`, `/cdate`, an `=1+2*3` calculator and `/1234.56` numerals. Each can be switched off in Settings.
  </Card>
  <Card title="Themes" icon="puzzle">
    `hufu_light`, `hufu_dark` and your own palette, with eight built-in themes rendered by the App. Install with a `hufu-ime://` link.
  </Card>
  <Card title="Typing statistics" icon="analytics">
    Off by default. When enabled they keep character counts, hours, apps and frequent words on this Mac — never full sentences, and you can clear them at any time.
  </Card>
  <Card title="Privacy" icon="padlock">
    Everyday typing is processed on your Mac and never uses the network. Only an AI action you start sends text to the model you chose.
  </Card>
  <Card title="Open source" icon="heart">
    Original code is MIT. librime, OpenCC and the rest keep their own licences; the Tiger-Code tables ship under their official release terms.
  </Card>
</CardGrid>
