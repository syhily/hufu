8 palettes, each rendered by the App. Click Install to confirm the import in Hufu Settings, or copy the YAML into your configuration.

<ThemeGallery />

Requires Hufu 0.1.0 or later; Hufu Settings asks you to confirm the import. Alternatively, copy the YAML into `hufu/imported/hufu.custom.yaml`.

Install links work directly; copying links and YAML needs JavaScript.

Want your own palette? Adjust background, text, highlight, radii and type size in Settings › Appearance, save it as “My palette”, or paste an edited version of the YAML above.
