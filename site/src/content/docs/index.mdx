import { Card, CardGrid } from '@astrojs/starlight/components';

<CardGrid>
  <Card title="只做虎码" icon="star">
    方案列表只有虎码（`tigress`）。官方秃版 2026.08.15 经 `dicts/huma` 引入，词表裁剪为单字与四字及以下词组。
  </Card>
  <Card title="词汇输入" icon="open-book">
    默认只出单字与自定义短语。打开后按简繁模式挂载三张词表：简体、打简出繁的预校验繁体、只繁。词表在构建期预编译。
  </Card>
  <Card title="简繁四模式" icon="translate">
    繁简混打按《通用规范汉字表》级别排序，另有打简出繁、只打繁体、只打简体。繁体标准可选虎码 `st_tu`、台湾正体、香港繁体、通用繁体。
  </Card>
  <Card title="便利功能" icon="rocket">
    `/time`、`/date`、`/week`、`/cdate`，`=1+2*3` 计算器，`/1234.56` 大写数字。都可以在设置里关掉。
  </Card>
  <Card title="主题" icon="puzzle">
    `hufu_light`、`hufu_dark` 与自定义配色，八套内置主题都由 App 实际渲染。`hufu-ime://` 链接一键导入。
  </Card>
  <Card title="输入统计" icon="analytics">
    默认关闭。打开后在本机记录字数、时段、应用分布与高频词，不保存完整句子，可随时清空。
  </Card>
  <Card title="隐私" icon="padlock">
    日常输入在本机处理，不联网。只有你主动执行 AI 动作时，目标文字才交给所选模型。
  </Card>
  <Card title="开源" icon="heart">
    原创代码 MIT。librime、OpenCC 等依赖保留各自许可；虎码词表按官方发布条款随包提供。
  </Card>
</CardGrid>
