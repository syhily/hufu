Install Hufu on your Mac.

Hufu 0.1.0 is available for macOS 15.0+. The installer is signed and notarized by Apple. Verification and installation steps are below.

Hufu 0.1.0

Preview · unsigned

Released 2026-10-21. This is an ad-hoc preview build without Apple notarization. Right-click › Open it the first time, or allow it under System Settings › Privacy & Security. Signing and notarization follow once a developer account is available.

Download · .pkg · 60 MB .zip (no installer)

Install step by step.

  1. Download the installer and SHA256SUMS.txt from the same folder. Run this command to verify it.
    shasum -a 256 -c SHA256SUMS.txt --ignore-missing
  2. Double-click the installer and follow the prompts. Or install with Homebrew:
    xattr -d com.apple.quarantine Hufu-0.1.0.pkg
  3. Open System Settings → Keyboard → Input Sources → Edit…, click + and add Hufu under Chinese, Simplified. If it is missing after the first install, log out and back in.

Or build from source.

Requires Xcode 26+ and XcodeGen. The script downloads and verifies pinned dependencies, then builds and registers the input method. The build uses ad-hoc signing.

git clone https://github.com/syhily/hufu.git && cd hufu
bash scripts/install-dev.sh

After an update, macOS starts the input process when you next type. Do not start it manually.
